BUSCADOR DE PALABRAS

PASOS PARA EJECUTAR EL PROYECTO

1. Descomprime la carpeta ZIP.
2. Abre la carpeta buscador_palabras en Visual Studio Code.
3. Abre una terminal dentro de esa carpeta.
4. Instala las dependencias:
   npm install
5. Compila el proyecto:
   npm run dev
6. Deja la terminal abierta mientras trabajas.
7. Abre index.html en el navegador.

FUNCIONES
- Captura de texto.
- Búsqueda sin distinguir mayúsculas/minúsculas.
- Conteo de coincidencias.
- Resaltado amarillo de coincidencias.
- Alertas con SweetAlert2.
- Botón para limpiar sin recargar la página.

NOTA
El archivo bundle.js se genera al ejecutar npm run dev.
Si no se ha generado todavía, primero ejecuta los comandos indicados arriba.
